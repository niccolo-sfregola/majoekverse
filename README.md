# maJoekverse

Hub web per la community di **maJoekoto** (streamer su Twitch, Instagram, YouTube, TikTok, Discord, Telegram): un unico posto per sapere se è live, vedere la schedule, le news, gli eventi e gli sponsor.

PWA (Progressive Web App): installabile su telefono e PC, tema scuro con i colori del brand.

## Stack

- [Next.js](https://nextjs.org) (App Router) + TypeScript + React
- [Tailwind CSS v4](https://tailwindcss.com) per lo stile
- [Supabase](https://supabase.com) (database + autenticazione) — in arrivo
- Login con Twitch — in arrivo
